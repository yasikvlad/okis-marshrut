# Маршрут Ксенії Окіс «Міні-продукт на AI за 7 кроків»

Агенти для б'юті-майстринь: кожен крок маршруту — одна кнопка.

| Крок | Агент | Статус |
| --- | --- | --- |
| 1. Ідея: що продавати | [`ideya-mini-produktu`](ideya-mini-produktu/) | готовий, v1.0 |
| 2. Програма продукту | `upakovka-mini-produktu` | у Ксенії, v0.2 |
| 3–7. Сайт, оплата, Reels, автовідповідь, реклама | — | у роботі |

## Як почати крок 1

1. Відкрий Claude (додаток або claude.ai). Увімкни пошук у інтернеті, якщо він вимкнений.
2. Встав у чат це посилання і напиши «Почни»:
   `https://raw.githubusercontent.com/yasikvlad/okis-marshrut/main/ideya-mini-produktu/START.md`
3. Далі Ксенія веде тебе сама. Тут неможливо щось зламати 🤍

Якщо Claude не відкрив посилання: скопіюй текст файлу [START.md](ideya-mini-produktu/START.md) у чат і напиши «Почни».

### Встановити як скіл (для учениць навчання)

Завантаж архів папки `ideya-mini-produktu` у Claude: Налаштування → Capabilities → Skills → завантажити. Після цього достатньо написати «почни».
