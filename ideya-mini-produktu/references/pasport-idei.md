# Паспорт ідеї: формат

Паспорт має дві частини. Обидві видаєш **у чаті текстом** (екран показує тільки красиву версію).

## 1. Людська частина (її мовою)

```
📜 Паспорт ідеї · [ім'я, якщо назвала]

💡 Твоя ідея: [назва-чернетка]
Для кого: …
Що отримають: … (до 10 слів)
Формат і ціна: …

Чому вона сильна
✅ Ти вмієш: …
✅ Людям треба: …
✅ Такого мало: …

Що вже продають (тільки для тебе, не для сайту)
• [назва] — [ціна] · [формат]  ×5–7
Висновок: …

Що болить у людей
1. «…» — [звідки]  ×5–7

Ще дві ідеї на майбутнє
• …
• …

Було → стало
Було: [її перша ідея або «ідеї не було»]
Стало: [обрана ідея]

🗺 Маршрут: ✅ 1. Ідея · ⬜ 2. Програма продукту · ⬜ 3–7
```

## 2. Технічний блок для агента кроку 2

Агент кроку 2 («Упаковка міні-продукту») читає саме ці поля і не питає їх удруге. Назви полів не перейменовуй і не перекладай (вони українські в будь-якій розмові). **Значення пиши мовою розмови.** Чого немає, пиши «немає». Усе, що не її слова, познач у кінці значення: `(пропозиція)` — твій варіант, який вона прийняла; `(здогадка)` — висновок без її підтвердження.

```
=== ПАСПОРТ ІДЕЇ v1 ===
Майстер: [ім'я або «немає»]
Мова розмови: [українська / російська]
Сфера: [брови, ламінування]
Країна і місто: [Польща, Варшава]
Мова покупців: [українська / польська / …]
Валюта: [грн / zł / € ]
Років у професії: [6]
Хвалять за: […]
Питають про: […]
Досвід навчання: [ще ні / подруг / учениць / вже є курс]
Кого вчить: [майстринь / клієнток]
Участь після покупки: [зовсім ні / трохи в чаті / готова до розборів]
Ціна її послуги: [… або «немає»]
Новий продукт чи оновлення: [новий / вже є курс, оновлюємо]
Не хоче робити: [… або «немає»]
Instagram: [посилання або «немає»]
--- Обрана ідея ---
Назва-чернетка: […]
Для кого: […] (для кроку 2 головне саме це поле, а не «Кого вчить»)
Рівень покупців: [початківці / досвідчені / і ті, і ті]
Мова покупців цієї ідеї: […]
Результат: […]
Формат: […]
Орієнтир ціни: [349–499 грн] (за знайденими)
Чому сильна: вмієш […] / людям треба […] / у конкурентів […]
Впевненість: [3 з 4]
Болі покупців: 1) «…» [звідки] 2) … 3) … 4) … 5) …
Сумніви покупців (здогадка): 1) … 2) … 3) …
Ціни конкурентів: [назва — ціна — формат]; […]; […]
Інші ідеї: 1) […] 2) […]
Перша ідея майстрині (до): [… або «немає»]
Дата: [дд.мм.рррр]
=== КІНЕЦЬ ПАСПОРТА ===
```
